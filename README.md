# Projeto Didelphis

Organizador de casos, lâminas, colorações especiais e laudos (mestrado em patologia de gambás).
Arquivo único (`index.html`), sem servidor. Dados salvos no navegador; use **Dados → Exportar backup**.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `didelphis`) e envie `index.html` e este README.
2. Settings → Pages → Source: *Deploy from branch* → `main` / `(root)`.
3. Acesse `https://SEU-USUARIO.github.io/didelphis/`.
